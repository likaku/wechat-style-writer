# 2026-04-09 工作日志

## Word 渲染器开发 — 零售长图同步输出 .docx (10:38)

用户要求在生成长图的同时生成完全一致的 Word 文件，方便上传公众号。

### 新增文件
- `word_renderer.py` — 基于 python-docx 的 Word 渲染器，API 与 CardRenderer v2 完全对应
  - 支持的渲染方法：render_h1/h2/h3/body/callout/quote/bullet/separator/image/data_row/footer/add_spacer
  - 视觉映射：NAVY 装饰线 → 段落边框、TEAL 竖线 → 左侧边框、浅灰底纹 → 段落底纹
  - **bold** 支持：解析行内 Markdown 加粗标记，加粗用 NAVY 色、Semibold 字重
  - 字体：PingFang SC / PingFang SC Semibold，标题用 Bricolage Grotesque Bold

### 修改文件
- `md_to_image_retail.py` — 重构为双通道渲染
  - `render_content(r, w)` 函数同时向 CardRenderer 和 WordRenderer 输出
  - 同一份内容，同步渲染 PNG + DOCX 两种格式
  - 运行时同时输出 `retail_poster.png`（750×13371px）和 `retail_poster.docx`（12MB）

### 输出
- `retail_poster.png` — 7.0MB，750×13371px
- `retail_poster.docx` — 12MB，包含 8 张图片 + 完整排版

## 修复 Word 图片与文字重叠 (11:10)

用户反馈 Word 文档中图片和文字重叠。根因：`render_image` 的段落继承了默认固定行距 `Pt(28)`，该行高比图片高度小得多，Word 将图片压缩到一行高度导致重叠。修复：将图片段落的 `line_spacing_rule` 设为 `WD_LINE_SPACING.SINGLE`，让图片完整显示。
